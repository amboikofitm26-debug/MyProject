\# MyProject



Навчальний проєкт для лабораторної роботи з системи контролю версій \*\*Git\*\*.



\## Опис



Консольний застосунок на C# (.NET 10), створений у Visual Studio 2026.

Репозиторій демонструє роботу з комітами, гілками та віддаленим сховищем GitHub.



\## Технології



\- C# / .NET 10

\- Visual Studio 2026

\- Git, GitHub



\## Запуск



1\. Клонувати репозиторій: `git clone https://github.com/amboikofitm26-debug/MyProject.git`

2\. Відкрити файл `MyProject.slnx` у Visual Studio

3\. Натиснути \*\*F5\*\*



\## Структура гілок



| Гілка | Призначення |

|-------|-------------|

| master | стабільна версія |

| develop | розробка нових змін |
